# Listas

## Lista desordenada

```md
- Elemento uno
- Elemento dos
- Elemento tres
```

- Elemento uno
- Elemento dos
- Elemento tres

## Lista ordenada

```md
1. Primer paso
2. Segundo paso
3. Tercer paso
```

1. Primer paso
2. Segundo paso
3. Tercer paso

## Listas anidadas

```md
- Frutas
  - Manzana
  - Pera
- Verduras
  1. Zanahoria
  2. Calabacín
- Legumbres
```

- Frutas
  - Manzana
  - Pera
- Verduras
  1. Zanahoria
  2. Calabacín
- Legumbres

## Listas mixtas

```md
- Paso uno: preparar
  1. Cortar
  2. Pelar
- Paso dos: cocinar
  - Hervir
  - Saltear
```

- Paso uno: preparar
  1. Cortar
  2. Pelar
- Paso dos: cocinar
  - Hervir
  - Saltear

## Notas

- La anidación se hace con **4 espacios** (o un tabulador).
- Los elementos de lista admiten todo el markdown: `**negrita**`, `[enlaces](#listas)`, código `` `inline` `` e incluso admoniciones y directivas anidadas.
- Si un elemento contiene un párrafo completo, añade una línea en blanco dentro del elemento.
